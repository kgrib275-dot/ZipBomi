# 집보미 콘텐츠 운영 기준

집보미는 **무료** 정보 서비스다. 구독자와 로그인 계정에 비용 없이 제공한다.
이 문서는 운영자가 게시물·데이터·메일을 다룰 때 지킬 기준과 정기 점검 목록이다.
법률 자문이 아니므로 애매하면 원 저작권자나 전문가에게 확인한다.

## 1. 유료 기능은 꺼 둔다
- 유료 월 구독은 `settings.ask.membership = false`(기본값)로 꺼져 있다.
  - 꺼져 있으면 신청 화면이 보이지 않는다. 신청 API는 404를 돌려주고, 처리방침의 "월 구독" 항목도 빠진다.
- 한 번이라도 돈을 받을 일이 생기면, 먼저 사업자등록과 통신판매업 신고를 한다.
  - 그다음 바닥글에 상호·대표자·사업자번호·주소·연락처를 표시하고 나서 기능을 켠다.
- 보미AI 횟수는 관리 > 회원 계정에서 **무료로** 늘려 준다. 대가를 받지 않는다.

## 2. 뉴스·유튜브 노트 (저작권)
수집한 원문(`full_text`)은 노트 초안을 쓰는 데만 쓰고, 공개 화면에는 내보내지 않는다.

| 할 것 | 하지 말 것 |
|---|---|
| 제목·매체명·날짜·원문 링크 표시 | 기사 문단을 그대로 옮기기 |
| 운영자 관점의 요약·해설·내 돈 계산 | 원문을 거의 다 담은 "요약" |
| 짧은 인용은 따옴표 + 출처 | 기사 사진·그래픽·유튜브 썸네일을 내려받아 다시 올리기 |
| 유튜브는 링크·임베드 | 유튜브 자막 전체를 글로 옮기기 |

게시 전 검토할 점:
- 노트 본문에 원문과 같은 문장이 3문장 넘게 이어지지 않는지 본다. 비슷하면 고쳐 쓴다.
- 원문 링크(`↗ 원문 보기`)가 살아 있는지 본다.
- 권리자가 삭제를 요청하면 **바로 비공개**로 돌리고 문의함에 처리 결과를 남긴다.
  - `sources.yaml`에서 그 출처를 끄는 것도 검토한다.
- 출처 사이트의 robots.txt나 이용약관이 수집을 막으면 그 출처를 끈다. 캡차·차단은 우회하지 않는다.

## 3. 생성형 AI 표시 (인공지능 기본법)
- 노트 초안과 보미AI 답변은 Google Gemini로 만든다. 다음 세 곳에 이 사실을 표시한다.
  - 노트 아래: "생성형 AI가 원문을 읽고 쓴 초안을 운영자가 검토해 게시"
  - 보미AI 패널과 `/ask`: "생성형 AI가 만든 결과물이라 틀릴 수 있음"
  - 바닥글: "노트 초안과 보미AI 답변은 생성형 AI로 만듭니다"
- 이 표시는 화면 문구에서 "AI" 단어를 쓰지 않는다는 규칙의 **예외**(법적 고지)다. 지우지 않는다.
- 운영자가 검토하지 않은 초안은 게시하지 않는다. 소개 페이지 FAQ도 그렇게 약속한다.
- 실재하지 않는 기자·편집자 이름을 쓰지 않는다. 쓴 사람은 "운영자"로 적는다.

## 4. 숫자·데이터
- 숫자에는 **출처와 기준일**을 붙인다. 출처·기준일이 없는 숫자는 게시하지 않는다.
- 현행 수치(대출 규제·세율 등)는 원문(법령, 금융위 발표)을 확인한 값만 올린다.
  - "확인 대기" 상태로는 공개하지 않는다.
  - 지금 남은 확인 대기 8건은 관리 > 현행 수치에서 처리한다.
- 데이터 출처별 이용 조건:

| 자료 | 출처 | 이용 조건 |
|---|---|---|
| 실거래가 | 국토교통부(공공데이터포털) | 출처 표시로 이용 가능 (공공누리·포털 이용약관) |
| 청약 공고·경쟁률 | 한국부동산원 청약홈 | 출처 표시. 경쟁률·가점 파일(15126242)은 활용신청 승인 후 사용 |
| 금리·심리지수·대출 잔액 | 한국은행 ECOS | 출처 표시 |
| **KB 매매·전세지수** | KB부동산(한국은행 ECOS 경유 포함) | **원 저작권자 KB. 재배포 조건을 KB 약관에서 확인**하고, 그래프·표에 "자료: KB부동산" 표시 |

- 화면의 숫자는 참고용이다. "투자 권유가 아님" 문구를 바닥글에 둔다.
- 특정 단지 매수·매도를 권하는 표현("지금 사세요", "오를 단지")은 쓰지 않는다.

## 5. 뉴스레터·알림 메일
- 무료 정보성 메일이다. 그래도 다음을 지킨다.
  - 구독 확인 메일을 거쳐 동의를 확인한다(이중 확인).
  - 모든 메일에 수신 거부 링크를 넣는다.
- 광고·제휴 내용을 넣게 되면, 제목에 "(광고)"를 붙이고 정보통신망법 광고성 정보 규정을 먼저 확인한다.
- 발송은 Gmail로 한다(하루 500통). 방문자가 일으키는 메일의 하루 상한은 로그인 메일 150통(링크+알림 = 300통), 구독 확인·연결 메일 120통이다. 구독자가 400명을 넘거나 상한 경보가 오면 발송 서비스를 옮길지 검토한다.

## 6. 개인정보
- 처리방침 v1을 2026-11-03에 시행했다. 운영자·보호책임자는 김성환, 연락처는 shkim.m01@gmail.com.
- 처리하는 항목이나 외부 업체가 바뀌면 관리 > 개인정보 처리방침에서 새 버전을 공지한다.
  - 시행 7일 전(중요한 변경은 30일 전)에 공지한다.
  - "기능이 바뀌어 다시 공지 필요" 표시가 뜨면 공지한다.
- 보미AI의 "내 공간 자료도 참고"는 **켤 때만** 보낸다(기본 꺼짐).
- Gemini 무료 등급은 입력이 Google 서비스 개선에 쓰일 수 있어 처리방침에 그렇게 적었다. 유료 등급으로 바꾸면 문구를 고친다.
- 회원 메모·일정·할 일은 본인만 본다. 운영자가 들여다보거나 통계에 쓰지 않는다.
