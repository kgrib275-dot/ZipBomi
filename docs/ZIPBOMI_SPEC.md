# 집보미 (집보미) — 공통 설계 (모든 작업자가 이 문서를 따른다)

AX Review(기업 AI 전환 뉴스·노트 서비스) 코드를 통째로 복사해, **부동산 전용 프라이빗 리서치 서비스**로 바꾼다.
구조·기능(수집 → 채점 → 노트 → 주간 흐름 → 뉴스레터, 오늘의 퀴즈·예측, 데이터 랩, 질문하기, 테스트들, 관리 화면)은 그대로 두고
**브랜드·색·데이터·문구·질의를 모두 부동산으로** 바꾼다.

## 브랜드
- 이름: **집보미** (한글 병기 **집보미**). 로고 글자: `ZIP` + `GENIE` (GENIE 를 노랑).
- 한 줄 소개: "내 집 마련과 부동산 결정을 위한 프라이빗 리서치"
- 부제: "흩어진 시세·정책·청약 정보를 매일 모아 읽고, 나에게 필요한 것만 정리해 둡니다."
- 회사명·특정 기업 브랜드는 어디에도 쓰지 않는다. "AX"·"AI 전환" 문맥은 남기지 않는다(부동산 AI 활용 같은 자연스러운 경우만 예외).

라이트 — 크림 바탕 + 진한 황토 강조(글자 대비 4.5:1 이상)

## 분류 (llm.CATEGORIES — 정확히 이 3개, 이 순서)
1. `시장·시세` — 매매·전월세 시세, 거래량, 지역별 동향, 금리와 시장
2. `정책·세금·대출` — 부동산 정책·규제, 세금(취득·보유·양도), 대출 규제(LTV·DSR), 임대차 제도
3. `청약·분양·개발` — 청약·분양, 재건축·재개발, 신도시·교통·개발 호재, 공급 일정

## 노트 유형 (llm.KINDS): `뉴스 분석`, `정책 해설`, `리포트`, `인터뷰`
## 대상 독자 (llm.AUDIENCES): `무주택 실수요자`, `1주택 갈아타기`, `다주택·투자자`, `임대인`, `임차인(전월세)`, `중개·실무자`

## 지역 (pipeline/industry.py 의 INDUSTRIES → 지역 사전으로 바꾼다. 화면 표기 '업종' → '지역')
`서울`, `경기`, `인천`, `부산·울산·경남`, `대구·경북`, `대전·세종·충청`, `광주·전라`, `강원·제주` — 각 지역의 시·구 이름 키워드(예: 서울=강남·서초·송파·마포·용산·성동…)로 판정.

## 테스트·퀴즈 (구조는 그대로, 내용만 부동산)
- 유형 테스트(/type, app/ax_types.py): "나의 부동산 성향 16유형" — 4축 예: 실거주(R)↔투자(I), 안정(S)↔공격(A), 입지(L)↔상품(P: 신축·평면), 데이터(D)↔현장(F). 유형 이름·설명·찰떡 유형·추천은 부동산 맥락.
- 커리어(/career, app/ax_tests.py): "나에게 맞는 내 집 마련 전략" — 청약형·급매형·경매형·갈아타기형·전세 유지형·분양권형 등.
- 습관(/habit): "부동산 공부 습관 진단" — 5영역: 시세 확인·정책 확인·임장(현장)·자금·대출 점검·기록·비교.
- 자가진단(/diagnosis): "내 집 마련 준비도 자가진단" — 3영역 12문항: 자금·대출 / 정보·지역 / 실행·계약.
- 용어 퀴즈(/terms, app/glossary.py): 두 트랙 "대출·청약 편", "세금·제도 편" — LTV·DSR·DTI·스트레스 DSR·전세가율·갭투자·청약 가점·특별공급·분양가상한제·재건축 초과이익환수·공시가격·종부세·양도세 비과세·임대차 2법·계약갱신청구권·확정일자·전입신고·근저당·경매·용적률·건폐율 등(트랙당 20개 이상). 정의는 정확하게, 수치(세율·비율)는 법령이 바뀌니 "2026년 기준 예시"처럼 단정하지 않는다.

## 수집 (config)
- sources.yaml: 부동산 뉴스·정책 출처. 키 없이 되는 RSS·공개 페이지 우선 — 국토교통부 보도자료, 한국부동산원 보도자료, 매경·한경·조선(땅집고)·머니투데이 부동산 섹션 RSS, Google 뉴스 RSS 검색(아파트 실거래가, 청약, 전세, 재건축, 부동산 정책, 주택담보대출, 분양 등 키워드별), 네이버 뉴스 검색(키 있을 때). 존재하는 RSS 주소인지 실제 요청해서 확인하고, 안 되는 주소는 넣지 않는다.
- keywords.yaml: 부동산 키워드(포함·제외·needs_ai 구조 그대로 — needs_ai 는 이름은 그대로 두되 '부동산 단어 동반 필요' 의미로 쓴다, filters.AI_ANCHORS 도 부동산 앵커(아파트·주택·부동산·전세·월세·청약·분양·재건축·집값·매매·LTV·DSR 등)로 바꾼다).

## 새 기능 (집보미 전용)
- `/deals` 실거래가: 국토교통부 아파트 매매 실거래가 API(공공데이터포털, .env `DATA_GO_KR_KEY`) — 시군구·년월로 조회, 평당가·㎡당 가격 통계, 결과는 DB 캐시. 키가 없으면 안내 화면.
- `/calc` 내 집 계산기: 대출 한도(LTV·DSR)와 월 상환액, 취득세 간이 계산, 청약 가점, 전세가율·갭 — 전부 브라우저 계산(LLM·외부 호출 없음).
- 관심 목록(프라이빗): 관심 지역·단지·메모를 방문자 상태(visitor_state)에 저장 — 다른 사람에게 보이지 않음.

## 지키는 것
- AX Review(포트 5012)와 완전히 분리: 포트 5030, DB `backend/data/zipbomi.db`, 쿠키 `zgv`, CSRF 헤더 `X-Requested-With: zipgenie`. AX Review 폴더는 절대 수정하지 않는다.
- LLM 토큰을 새로 쓰는 기능은 만들지 않는다(기존 채점·노트·질문하기만). 계산기·실거래가는 토큰 없이.
- 가짜 데이터를 실제처럼 보이게 하지 않는다. 데이터가 없으면 빈 상태 안내.
